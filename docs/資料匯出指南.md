# 後端資料匯出指南

本專案的研究資料位於 Supabase PostgreSQL 的 `wenyan` schema。瀏覽器端不能直接讀取資料表；研究者可使用 Supabase Dashboard 或受密碼保護的管理者 API。

## 方法一：Supabase Dashboard

1. 登入 Supabase，開啟 `wenyan-pilot` 專案。
2. 進入 SQL Editor。
3. 每次只執行一個唯讀查詢：

```sql
select * from wenyan.participants order by sequence;
select * from wenyan.responses order by sequence;
select * from wenyan.interactions order by sequence;
select * from wenyan.events order by sequence;
select * from wenyan.scales order by sequence;
```

4. 在 Results 區按 Export，選 CSV。
5. 五張表分別保存；不要只下載 `participants`。

如果 SQL Editor 在重設資料庫密碼後顯示 `password authentication failed`，先重新載入 Dashboard。仍失敗時登出再登入 Supabase；不要再次重設密碼，也不要停用 TLS。

## 方法二：管理者 API 下載 CSV

### 一次性設定

在 Vercel 專案 `wenyan-pilot-v5.5` 的 Environment Variables 新增：

```text
ADMIN_PASSWORD=<由密碼管理器產生的長隨機密碼>
```

類型選 Secret、環境選 Production，然後重新部署。不要使用 `change-me`，不要把密碼放進網址、Git、截圖或論文附件。

### PowerShell 下載

在專案資料夾開啟 PowerShell：

```powershell
$exportBase = 'https://wenyan-pilot-v55.vercel.app'
$env:ADMIN_PASSWORD = Read-Host '輸入 ADMIN_PASSWORD' -MaskInput
$exportFolder = Join-Path (Get-Location) ('backups/api-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
New-Item -ItemType Directory -Path $exportFolder
$headers = @{ Authorization = "Bearer $env:ADMIN_PASSWORD" }
$tables = 'participants','responses','interactions','events','scales'
foreach ($table in $tables) {
  Invoke-WebRequest -Uri "$exportBase/api/admin/export?table=$table" -Headers $headers -OutFile (Join-Path $exportFolder "$table.csv")
}
Invoke-WebRequest -Uri "$exportBase/api/admin/summary" -Headers $headers -OutFile (Join-Path $exportFolder 'summary.json')
Remove-Item Env:ADMIN_PASSWORD
```

成功後，`backups/api-時間/` 會包含五個 CSV 和一個摘要 JSON。`backups/` 已排除於 Git，但仍需移到有存取控制及備份的研究儲存位置。

## 五張表的用途

| 表 | 一列代表 | 主要用途 |
|---|---|---|
| `participants` | 一位參與者 | 組別、階段、前測分層、排除／描述旗標、研究版本 |
| `responses` | 一題測驗作答 | S1、S3、S5、S6 的選項、正誤與反應時間 |
| `interactions` | 一個 AI／讀者對話回合 | 反白文字、策略、模型原始輸出、生成選項、降級狀態 |
| `events` | 一個操作或稽核事件 | 階段進出、全螢幕離開、理由判定、互動完成位置 |
| `scales` | 一位參與者的 S4 量表 | 八題認知負荷分數及三個分量表平均 |

## 認知負荷欄位

`scales` 的 v5.6 新資料包含：

```text
intrinsic1, intrinsic2, intrinsicMean
germane1, germane2, germane3, germaneMean
extraneous1, extraneous2, extraneous3, extraneousMean
```

舊乾跑資料可能只含 `mentalEffort`，或更早期的 `load`、`frustration`、`selfEfficacy`。不可把不同版本的欄位當成同一量表合併。以每列 `configVersion` 判斷版本。

## 安全界線

- `participants` 含主流程與延遲測驗 token；token 等同存取憑證。
- `interactions.rawResponse` 可能包含模型輸出及參與者輸入。
- 直接用試算表開 CSV 時，以純文字匯入自由文字欄，避免公式執行。
- 對外分享前另做去識別，只保留分析需要的欄位。
- `summary.json` 是營運摘要，不可代替正式統計分析。
