# 認知負荷量表：八題多向度量表

## 本研究採用的測量

S4 採用 Klepsch、Schmitz 與 Seufert（2017）第二版 naïve-rating questionnaire 的繁體中文研究翻譯。它分開測量：

- 內在認知負荷（intrinsic cognitive load）：2 題
- 外在認知負荷（extraneous cognitive load）：3 題
- 增生認知負荷（germane cognitive load）：3 題

參與者不會看見構面名稱。全部題目採 1–7 點量尺：1＝完全不符合，7＝完全符合。

| 欄位 | 題目 |
|---|---|
| `intrinsic1` | 剛才閱讀時，我需要同時在腦中處理很多資訊。 |
| `intrinsic2` | 剛才的閱讀任務很複雜。 |
| `germane1` | 我有努力不只理解個別字句，也理解文章的整體脈絡。 |
| `germane2` | 閱讀時，我力求正確理解文章的所有內容。 |
| `germane3` | 剛才的閱讀介面包含一些有助於我理解文章的元素。 |
| `extraneous1` | 剛才閱讀時，要找出重要資訊讓我感到吃力。 |
| `extraneous2` | 剛才閱讀介面的呈現方式不利於我理解文章。 |
| `extraneous3` | 剛才閱讀時，我難以辨認並連結文章中的重要資訊。 |

第 5 題是原作者標為適合「教材刻意加入提示或理解支援」時使用的題目。本研究正是比較不同 AI 支援方式，所以保留。

## 計分

- `intrinsicMean = (intrinsic1 + intrinsic2) / 2`
- `germaneMean = (germane1 + germane2 + germane3) / 3`
- `extraneousMean = (extraneous1 + extraneous2 + extraneous3) / 3`

伺服器保存八個原始題分及三個平均數。三種負荷的理論方向不同，**不可把八題加成一個總分**。正式分析需分構面報告，並在本研究樣本中分別檢查內部一致性；N=45 的信度估計不會很精確。

## 測量時點

流程是 S2 閱讀與 AI 操弄 → S4 認知負荷量表 → S3 同篇立即理解 → S5 新篇遷移。量表緊接 S2，避免評分混入後續測驗本身的負荷。

## 可以與不可以宣稱的內容

- 可以稱為「依 Klepsch 等人（2017）製作的繁體中文研究翻譯」。
- 可以分別分析內在、外在及增生認知負荷。
- 不可稱為 NASA-TLX；NASA-TLX 測量較廣泛的主觀工作負荷。
- 不可稱為已針對香港大學生文言文閱讀驗證的繁體中文版。
- 中國大陸已有 Leppink 十題 MDT-CL 的中文驗證，但對象是 ICU 護理人員；改寫到本研究後不能直接移植其效度證據。
