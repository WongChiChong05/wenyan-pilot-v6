## 摘要

一對一輔導是最有效率的教學方法之一。隨著大型語言模型（Large Language Models, LLMs）日益普及，人們開始嘗試建立以 LLM 為基礎的對話式導師，使每個人都能享有一對一輔導的益處。然而，目前的 LLM 主要被訓練成有用的助理，缺乏關鍵的教學技能。例如，它們經常很快就把解法告訴學生，也無法為更豐富的多回合教學互動作出規劃。若要在教學情境中使用 LLM，就必須引導它們採用有效的教學策略；我們將這個問題稱為「教學導向調控」（Pedagogical Steering）。

我們開發了 StratL：一種最佳化 LLM 提示詞的演算法，用來引導模型遵循以轉移圖（transition graph）表示的預先定義多回合輔導計畫。作為案例研究，我們依循一種先進且有效的學習設計——生產性失敗（Productive Failure, PF）——建立高中數學原型導師。為了在真實世界情境中驗證我們的方法，我們對新加坡 17 名高中生進行實地研究，結果顯示 StratL 能成功引導 LLM 遵循 PF 輔導策略。最後，我們指出 LLM 教學導向調控所面臨的挑戰，並藉由公開 PF 題目資料集[^1]與程式碼[^2]，提供進一步改進的機會。

[^1]: 資料集（Dataset）。
[^2]: 程式碼（Code）。

## 1 引言

一對一輔導是一種有效的教學方法（Bloom, 1984）。由於輔導的成效很高，但成本又令人難以負擔，因此，尋找可擴展且負擔得起的一對一輔導方案，被視為教育領域最大的問題之一；這就是所謂的「兩個標準差問題」（Two-Sigma Problem）（Bloom, 1984; Cohen et al., 1982）。隨著大型語言模型（LLMs）日益普及，使用它們建立對話式輔導系統、藉此降低輔導成本的興趣也持續增加（Jurenka et al., 2024; Khan, 2023）。然而，先前研究已指出 LLM 缺乏教學特性（Macina et al., 2023b; Tack and Piech, 2022）。大多數 LLM 都經過指令調校，以針對廣泛的人類偏好進行最佳化（Ouyang et al., 2022; Zhang et al., 2023），因此會產生類似助理的回應。然而，導師的目標是最大化學習，而不是使用者滿意度。

這兩個目標可能互相矛盾。例如，當學生尋求協助時，直接提供解法很可能最能提高他們的滿意度，也是 LLM 偏好的回應（Macina et al., 2023a）。然而，從學習角度來看，更有效率的做法是促進學生主動參與，讓他們在認知上投入問題，例如提供間接提示，或提出引導性問題（Freeman et al., 2014; Merrill et al., 1992）。此外，現有的 LLM 導師主要針對單回合請求進行最佳化與評估，但輔導對話應被視為教師與學生之間的多回合互動；教師會在其中使用各種教學線索（Merrill et al., 1992）。由於 LLM 原本不是為輔導而設計，我們把它們從服務使用者的目標，轉向適合教學的目標，並將此轉變定義為「教學導向調控」問題。

我們提出並評估 StratL，一種用 LLM 建模多回合輔導策略的演算法。我們把多回合策略定義為一連串單回合教學目標，並稱之為「輔導意圖」（tutoring intents）。StratL 使用轉移圖，在每次學生發言之後動態重新定義輔導意圖，再提示 LLM 於下一回合遵循這些意圖。我們與學習科學家合作，整合一種以「生產性失敗」（PF）（Kapur, 2008, 2024）為基礎的策略；研究顯示，這種進階學習設計對人類學習的成效高於其他傳統教學方法（Sinha and Kapur, 2021）。

PF 可以被視為「不直接把答案告訴學生」最極端的版本。在 PF 中，學生會受到鼓勵去探索一個結構不完整的問題，例如使用蘇格拉底式提問（Socratic questioning）（Shridhar et al., 2022），並接觸各種次佳解法，即使這會導致失敗。PF 可以應用於不同學科，但本研究聚焦高中數學，因為高中數學是 PF 研究中探索最多的領域（Sinha and Kapur, 2021）。

我們透過模擬學生的前期研究，以及一項包含新加坡 17 名高中生的實地研究，評估 StratL，並揭示教學導向調控問題的實務限制與觀察。結果顯示，StratL 能有效引導 LLM 遵循 PF 輔導策略，而且不會對 LLM 其他理想特性造成負面外溢效果。

我們的貢獻如下：

- 我們在 LLM 多回合輔導的脈絡中定義「教學導向調控」問題。我們提出 StratL 演算法，建立輔導策略概念的模型，並利用一系列單回合意圖，提示 LLM 朝指定策略行動。
- 我們公開第一個 PF 輔導練習資料集。這些開放式練習包含多種次佳解法，需要多次互動才能找到最佳解法。
- 我們在新加坡一所高中進行實地測試，以評估 StratL 在真實世界中的潛在影響。我們使用受學習科學啟發的新指標，測量 StratL 及其消融版本（ablations）控制教學方法的程度，並研究其限制。

### 圖 1 解讀

圖 1 比較同一段學生求助，在未受控制與受 StratL 控制時的兩條路徑。左側顯示一般 LLM 容易順從學生，直接提供答案；藍色流程則先把學生發言分類成狀態特徵，再由確定性的轉移圖選擇教學意圖，最後把相應的短提示詞片段加入基礎提示詞。LLM 只負責根據選定意圖產生文字，不負責自行選擇整體教學策略。

## 2 背景與相關研究

### 2.1 LLM 的教學缺陷

近期進展使最先進的 LLM 系統能可靠完成國中至高中程度的數學問題，例如使用提示方法（Wu et al., 2023; Kojima et al., 2022）、結合一致性抽樣的多重抽樣策略（Wang et al., 2023）或精煉方法（Madaan et al., 2024; Shridhar et al., 2024; Li et al., 2023）、微調（Zelikman et al., 2022; Yuan et al., 2023），或使用符號求解器、程式碼直譯器等外部工具（He-Yueya et al., 2023; Mialon et al., 2023）。

儘管 LLM 的能力很有前景，多項研究仍展示了它們不佳的教學特性（Tack and Piech, 2022）。在其他缺陷之外，大多數模型經常把練習解法透露給學生，即使提示詞要求它們不要這樣做也是如此（Macina et al., 2023a）。這些教學限制源自一個核心問題：LLM 並未針對輔導進行最佳化。基礎語言模型完成初始預訓練後，還需要經過對齊（alignment）階段，才能變成像 ChatGPT 一樣有用、能遵循人類指令的助理。這種對齊通常透過人類偏好來微調 LLM（Zhang et al., 2023），主要採用「基於人類回饋的強化學習」（Reinforcement Learning with Human Feedback, RLHF）（Ouyang et al., 2022）。在這個過程中，LLM 透過最佳化使用者滿意度來學習遵從請求。

因此，LLM 助理會產生針對人類偏好最佳化的文字。這與導師應有的行為並不一致。事實上，學生求助時，導師不應必然最大化學生滿意度，而應最大化他們的學習。為此，導師的意圖（例如反問一個問題）可能不同於學生希望導師做的事（例如直接給出解法）。這種不匹配是 LLM 作為導師的核心限制之一。

### 2.2 用於輔導的 LLM

多項研究嘗試處理 LLM 缺乏教學特性的問題。最簡單直接的方法是撰寫一個詳盡提示詞（Wang et al., 2024b; Sonkar et al., 2023; Pal Chowdhury et al., 2024）。然而，要用文字列舉導師所有應有行為相當複雜，尤其是細緻的教學策略。

另一種被考慮的方法，是把 LLM 微調成採用有效的輔導策略。然而，監督式微調受到輔導資料集稀少的限制，因為收集這類資料成本高昂，而且涉及倫理疑慮（Kasneci et al., 2023）。Macina et al.（2023a）採用反向「綠野仙蹤」（Wizard-of-Oz）方法，請真人教師輔導由 GPT 模擬的學生，建立完整的高品質輔導對話資料集；結果顯示，使用此資料集微調 LLM 能改善其教學表現。

同樣地，CLASS 框架（Sonkar et al., 2023）及 Book2Dial（Wang et al., 2024a）使用 LLM 生成包含學生—導師互動的合成對話資料集，再微調較小的 LLM。然而，這些對話的品質並未受到評估，而且容易產生幻覺。此外，微調成本高昂，也會把 LLM 限制在訓練資料中的特定教學風格，因此不同教學方法需要不同資料集。LearnLM（Jurenka et al., 2024; LearnLM Team, 2024）透過整合教學指令遵循調校來緩解此問題，但仍高度依賴合成資料，以及成本高昂的共同訓練流程；在此流程中，LearnLM 會與通用 LLM 一起接受訓練。

Bridge 方法（Wang et al., 2024b）是我們其中一項基準方法的靈感來源。它使用 LLM 根據對話歷史分類學生錯誤，並決定導師介入。以 Bridge 為基礎的系統讓 LLM 自行選擇輔導策略，並假設它有能力作出教學上合理的選擇。

相較之下，我們的方法著重讓學習科學家控制輔導行為。為此，我們使用結構化的教學意圖選擇：根據已分類的學生狀態，利用轉移圖選擇意圖，使專家能約束模型，在多回合對話中更忠實地遵循指定教學方法。

### 2.3 生產性失敗（PF）

教育領域廣泛採用「先教學、後解題」（Instruction followed by Problem Solving）方法：先直接教導學生如何處理問題，再讓他們練習。然而，PF（Kapur, 2008, 2016）採用相反順序。

PF 是一種「先解題、後教學」（Problem Solving followed by Instruction）的學習設計。學習者先嘗試解決開放式問題，之後才正式學習處理方法，藉此建立更深入的主題理解。在 PF 中，教師主要透過提問，讓學生在認知上投入問題。大量證據顯示 PF 有效；統合分析指出，與傳統教學相比，其效果量為 0.87 個標準差（以學習科學的標準而言屬高）（Sinha and Kapur, 2021）。

成功的 PF 解題過程會讓學習者有機會探索問題，並盡可能建立更多「表徵與解題方法」（Representation and Solution Methods, RSMs），即使最後未能解決問題也沒有關係（Kapur and Bielaczyc, 2012）。簡單來說，這些 RSM 可以被視為問題的心理表徵，或彼此獨特的解題嘗試。生成的 RSM 數量，是預測學生能從 PF 學到多少的最佳指標之一（Kapur and Rummel, 2012）。因此，我們的輔導策略旨在促進 RSM 的生成，並將其數量作為其中一項評估指標。

總體而言，PF 適合用來驗證我們的方法，原因有二：（1）它是一種已被廣泛證明成功的教學策略；（2）它與 LLM 的原生行為相反，因為 PF 導師不應直接向學生透露解法。

## 3 方法

### 3.1 形式化定義

#### 對話式輔導任務

我們擴充 Macina et al.（2023b）所定義的對話式輔導任務形式化表示。我們考慮一段輔導對話歷史 \(H_{\le n}=(u_1,\ldots,u_n)\)，其中包含多個輔導回合 \(u_t=(y_t,x_t)\)；\(y_t\) 是導師在第 \(t\) 回合的發言，\(x_t\) 則是學生的發言。每段導師發言都與一組輔導意圖 \(i_t\) 相關，而其中的元素是從意圖分類體系 \(I=\{I_1,\ldots,I_{|I|}\}\) 中選出。

意圖被定義為導師發言的目標，例如「糾正學生的錯誤」。我們以 \(K\) 表示基礎情境資訊（grounding information），亦即提供給 LLM、用來補充脈絡的資訊。在我們的案例中，\(K\) 包含輔導題目及其解法。由此得到的條件生成模型會產生：

\[
y_{n+1}\sim p\bigl(y\mid i_{n+1},H_{\le n},K\bigr) \tag{1}
\]

#### 輔導策略建模

我們把輔導策略函式定義為函式 \(\phi\)：它以基礎情境資訊及截至任一回合 \(t\) 的對話歷史 \((K,H_{\le t})\) 為輸入，並輸出第 \(t+1\) 回合的一組單回合輔導意圖 \(i_{t+1}\subseteq I\)。抽象而言，\(\phi\) 表示一名專家導師根據對話脈絡，從教學角度選出最佳意圖、用來回應學生上一段發言的決策過程。實務上，這個函式將由下一段所介紹的近似函式 \(\tilde{\phi}\) 取代。由此得到的條件式導師模型會依下式生成 \(y_{n+1}\)：

\[
y_{n+1}\sim p\bigl(y\mid \phi(H_{\le n},K),H_{\le n},K\bigr) \tag{2}
\]

#### 學生狀態追蹤

專家導師會根據以下觀察決定介入方式：（1）學生的情緒或知識狀態（Lepper et al., 1993）；（2）對話狀態與導師先前的介入（Merrill et al., 1992）。例如，導師不會用完全相同的方式處理計算錯誤與推理錯誤。

因此，我們把下一段定義的狀態特徵（1）及先前的輔導意圖（2），作為意圖選擇函式 \(\tilde{\phi}\) 的輸入。

每個學生回合都與一組狀態特徵 \(s_t\) 相關，用來描述學生及對話在第 \(t\) 回合的狀態。這些狀態特徵從所有可能特徵的集合 \(S\) 中選出。\(S\) 中的特徵可以是「學生感到困惑」，或「學生犯了計算錯誤」。我們以 \(\psi\) 表示一個分類器，它根據對話歷史及基礎情境資訊提供這些特徵。

因此，我們的意圖選擇函式寫成 \(\tilde{\phi}(i_n,s_n)=i_{n+1}\subseteq I\)。如前所述，\(\tilde{\phi}\) 取決於學生狀態特徵 \(s_n\) 及先前的導師意圖 \(i_n\)。最終的條件生成模型會產生：

\[
y_{n+1}\sim p\bigl(y\mid \tilde{\phi}(i_n,\psi(H_{\le n},K)),H_{\le n},K\bigr) \tag{3}
\]

### 3.2 演算法

為了引導 LLM 採用多回合教學策略，我們針對第 3.1 節的形式化表示式（3）提出 StratL 演算法。StratL 會在每段學生發言之後動態更新輔導意圖，並提示 LLM 在單一回合層次遵循這些意圖。圖 1 顯示 StratL 的視覺化表示。此演算法由三個子程序構成：I. 學生狀態追蹤、II. 導師意圖選擇，以及 III. 意圖相依調控。

#### I. 學生狀態追蹤

學生狀態追蹤對應函式 \(\psi\)。這一步會對對話歷史及第 \(t\) 回合最新的學生發言進行多標籤分類。被選取的特徵 \(s_n\) 來自預先定義的可能特徵集合 \(S\)。這些特徵分為四類：（1）錯誤類型；（2）學生請求；（3）對話狀態；（4）情緒狀態。

這四類特徵都會為意圖選擇提供重要資訊：（1）協助規劃錯誤補救，例如推理錯誤與計算錯誤不應用相同方式處理（Daheim et al., 2024; Wang et al., 2024b）；（2）不同學生請求需要不同反應，例如學生要求解法，與要求定義時不能使用相同回應；（3）協助組織對話，例如判斷問題是否已解決；（4）讓導師能作出適當的情緒回應（Lepper et al., 1993）。我們使用的確切特徵詳見附錄 B.2.1。

狀態追蹤由一個 LLM 執行；該 LLM 會收到可能學生狀態集合 \(S\) 及對話歷史，並被提示辨識這些不同特徵。我們所用提示詞等實作細節見附錄 B.2.1。

#### II. 導師意圖選擇

導師意圖選擇對應函式 \(\tilde{\phi}\)。我們把導師意圖選擇建模為一個確定性轉移：從先前的意圖集合 \(i_n\) 轉移到下一組意圖 \(i_{n+1}\)，並以步驟 I 的輸出 \(s_n\) 為條件。轉移規則由一名學習科學專家定義，並以圖表示。請注意，與傳統的確定性狀態轉移模型不同，我們的圖允許沿著多條並行轉移，從一組節點移到另一組節點。

我們使用鷹架理論（Scaffolding）（Reiser, 2004）、情感認知（Affective Cognition）（Lepper et al., 1993），以及 PF（Sinha and Kapur, 2019; Kapur and Bielaczyc, 2012），設計輔導意圖分類體系 \(I\)。這些意圖主要分成兩類：（1）鷹架意圖（scaffolding intents），透過限制解答空間協助學生，例如給予提示；（2）問題化意圖（problematizing intents），透過探索解答空間協助學生深化理解，例如要求學生把直覺形式化。

在我們的 PF 策略中，學生卡住時會優先使用鷹架；學生展現對問題的理解時，則使用問題化意圖，鼓勵他們自由探索問題並生成多個 RSM。完整分類體系見附錄 B.1 的表 5；我們用來設計 PF 意圖選擇的學習科學原理，則在附錄 B.3 中詳細說明。

我們的 PF 意圖選擇圖呈現在圖 2。每個節點代表 \(I\) 中的一個意圖，箭頭代表意圖之間的轉移。我們從「要求下一步」（Ask for the Next Step）節點開始，並在每個輔導回合移動。箭頭邏輯條件中所使用的字母，是學生狀態追蹤特徵的代碼（詳見附錄 B.2.1 的圖 8）。為了使圖表清楚，任何意圖都能採取的轉移，會用沒有起始節點的箭頭表示。

#### III. 意圖相依調控

意圖相依調控會根據選取的輔導意圖 \(i_{n+1}\)，生成 LLM 導師提示詞 \(p_{n+1}\)。我們在 \(I\) 中的意圖與短提示詞片段之間，定義一對一對應關係。確切對應見附錄 B.2.2。

### 圖 2 解讀

圖 2 是一張多節點、可同時觸發多條邊的規則圖，不是只能位於單一節點的傳統有限狀態機。系統以「要求學生說出下一步」為預設起點；若狀態追蹤判定學生卡住、犯錯、需要計算、需要反思或已完成，便依 `a` 至 `m` 的布林條件轉移到相應意圖。沒有起點的垂直箭頭表示全域規則，可從任何目前意圖觸發。

對 `wenyan-pilot` 的意義：目前三層階梯比 StratL 簡單，而且主要根據選項正誤與理由門檻轉移。若未來加入更精細的澄清、重問或錯誤類型處理，可以參考「狀態分類與轉移規則分離」的架構；但不應讓 LLM 直接決定 explanation 是否解鎖。

## 4 實驗

### 實驗設定

作為案例研究，我們使用 StratL 實作一個高中數學導師原型。此原型以 GPT-4o（`gpt-4o-2024-08-06`）為基礎，並遵循受 PF 啟發的輔導策略。導師每段輔導對話討論一個問題，而且可以存取該題的解法。我們在原型中使用的確切提示詞，以及完整的狀態特徵清單、意圖分類體系與意圖—提示詞對應，都列於附錄 B.2。

### 4.1 研究問題

我們透過評估原型遵循 PF 範式的能力，驗證系統控制 LLM 所採輔導策略的能力。理想情況下，這項控制不應妨礙 LLM 的事實正確性，或連貫性等理想對話特性。我們將這些目標寫成兩個研究問題：

- **RQ1：** StratL 能在多大程度上使 LLM 導師遵循 PF？
- **RQ2：** StratL 是否會影響 LLM 導師的其他理想特性？

我們選擇在 PF 專家協助下，手工設計意圖選擇機制。這與 Wang et al.（2024b）讓 LLM 選擇如何回應的做法不同。因此，我們提出一個設計問題來檢驗假設：

- **DQ1：** 由 LLM 進行的意圖選擇，與我們的方法相比表現如何？

### 4.2 資料集

我們彙整了一個包含 15 道 PF 問題的資料集。這些問題具開放性、結構不完整，而且能引起參與。它們包含多個次佳解法（及單一最佳解法），也需要學生經過多次互動才能探索解答空間，因此是評估輔導系統教學技能的高品質測試題。

我們在兩道九年級數學題上測試演算法；實地測試中，有 62% 的學生成功解出這些題目。第一題「一致性」（Consistency）改編自 Kapur and Toh（2015），是一道已有充分研究的發明型問題：學生需要設計一個一致性測量方法（通常是變異數），比較足球員的表現。對這道題而言，有效的 PF 導師應協助學生建構盡可能多的一致性測量方法。

第二題名為「國家」（Country），取自 Kerrigan（2018）。這是一道開放式問題，要求學生根據各州人口公平分配投票席次。對這道題而言，有效的 PF 導師應引導學生推理，但不能明確提供關鍵步驟，例如使用比例概念。確切題目敘述、解法，以及資料集規格、預定用途與授權，見附錄 A.1 與 A.2。

### 4.3 基準版本

我們把 StratL 控制的導師 LLM（V1）與三個消融版本比較：

- **V2：無意圖（No Intent）。** 基準 LLM，只使用基礎提示詞要求它扮演導師，不加入意圖相依提示詞。
- **V3：固定意圖（Constant Intent）。** 永遠使用同一意圖，即附錄 B.1 表 5 的「要求下一步」；它只要求學生繼續完成練習。我們用此基準評估意圖選擇程序的重要性。
- **V4：LLM 意圖（LLM Intent）。** 使用 LLM 執行意圖選擇；其提示詞見附錄 B.2.3（Wang et al., 2024b）。我們用此版本回答 DQ1。

### 4.4 評估指標

為了定量評估不同版本對 PF 的忠實度，也就是它們遵循 PF 的成功程度，我們必須使用代理變項。我們提出的主要代理指標是學生生成的「表徵與解題方法」（RSM）數量；RSM 可以被理解為學生表徵問題及嘗試解題的不同方式。如第 2.3 節所述，學生生成的 RSM 多樣性，是 PF 學習增益的首要預測指標（Kapur and Bielaczyc, 2012; Kapur and Rummel, 2012）。因此，我們使用 RSM 數量測量導師對 PF 的忠實度。

然而，不是每個問題都容易產生多個 RSM。在我們的研究中，只有「一致性」具有這項特性。因此，我們另外定義「PF 分數」（PF Score）作為另一個代理指標。

PF 的核心理念之一，是鼓勵學生自己探索問題，藉此建構自己的理解，即使最後未能解出問題也無妨。根據這項理念，我們為每道題定義一套評分規準，用來計算導師的 PF 分數：針對每道題，我們辨識出一組關鍵推理步驟，代表對問題的不同概念理解。評估一段輔導對話時，學生每自行發現一個關鍵推理步驟，導師就得到一分。如果該步驟由導師透露，或由導師直接提示，則不給分。

這項指標可以被視為經調整的子步驟成功率。有效的 PF 導師會協助學生探索問題，使他們達到這些概念理解，同時又不直接提示或透露內容，因此會得到較高的 PF 分數。兩道測試題的確切子步驟列於附錄 A.3。

### 4.5 使用模擬學生的前期研究

基於倫理疑慮（Kasneci et al., 2023），我們在讓真人參與前，先使用 GPT-4 模擬學生測試原型。這種使用模擬學生的方法稱為互動式輔導（interactive tutoring），已被相關文獻採用（Macina et al., 2023a; Sonkar et al., 2023）。

重要的是，我們不假設 LLM 能準確模擬學生的學習。不過，我們的前期研究不需要這項假設，因為我們關注的是演算法遵循 PF 輔導策略的能力，而不是它帶來的學習增益。我們針對兩道問題及四個導師版本（V1–V4），每種組合模擬三段對話，再使用評分規準標註對話，計算 PF 分數與 RSM 數量（如第 4.4 節所述）。

### 4.6 學生實地測試

我們在新加坡一所高中，對 17 名九年級學生進行實地測試。每名學生以均等機率隨機分配到兩個條件之一（V1 或 V2；選擇理由見第 5.1 節），以及兩道練習之一。他們有 15 分鐘與導師互動。我們依評分規準人工標註對話，計算 PF 分數及生成的 RSM 數量。

#### 研究後問卷

輔導階段結束後，學生會回答與經驗有關的問題，以評估 StratL 是否對導師 LLM 的理想特性造成潛在外溢效果。他們使用三點李克特量表（Likert scale），從以下方面評分 AI 導師：（a）連貫性；（b）同理心；（c）有用性。

#### DQ1

只用自然語言描述輔導策略並提示 LLM，並不足以完成意圖選擇。表 1 的前期研究結果顯示，StratL（V1）能成功引導 LLM 導師採用 PF；證據是此版本引出的 RSM 數量較多。我們觀察到，讓 LLM 負責意圖選擇的 StratL 版本（V4），表現優於基準 LLM（V2），但不如採用手工設計意圖選擇機制的 StratL。

這項結果為 DQ1 提供部分答案：只提供應遵循輔導策略的自然語言描述，再讓 LLM 自行選擇相應意圖，無法在輔導策略忠實度上得到令人滿意的結果。

#### RQ1

由 StratL 控制的 LLM 所遵循的策略，是由意圖選擇程序決定。整體而言，V3 在兩道題上取得相當高的 PF 分數，因為它從不向學生提供任何提示。然而，這個結果更可能是 PF 分數定義方式造成的，而不是 PF 忠實度的表現，因為 V3 在第二個代理指標上的表現較差：它無法像 V1 一樣讓學生產生較多 RSM，平均只有 1.34 個。

這顯示，由 StratL 控制的 LLM 所採策略是由意圖選擇程序決定，因為 V1 與 V3 之間唯一不同的部分就是該程序。

根據 DQ1 與 RQ1 的初步答案，我們決定不把 V3 與 V4 納入真人學生的實地測試；如此可聚焦表現最佳的版本（V1），同時保留不使用 StratL 的基準版本（V2）作比較。

#### 學生狀態追蹤的準確度

StratL 整體運作有賴學生狀態追蹤正常運作。為了測試其可靠性，我們針對兩道題各生成十段輔導對話，再由第一作者以真實標準狀態特徵 \(s_t\) 進行人工標註。我們把學生狀態追蹤的輸出與標註資料比較。

由於這是一項多標籤分類任務，我們針對每個狀態特徵計算精確率（precision）、召回率（recall）及 F1 分數。我們比較學生狀態追蹤步驟的三種不同實作；方法與結果詳見附錄 A.4 的表 4。我們的實作得到 0.77 的微平均 F1（micro F1），表現令人滿意。學生狀態追蹤本身是一項獨立任務，我們鼓勵研究者嘗試不同分類模型，以改善其可靠性。

### 5.2 學生實地測試：衡量端到端成效

#### RQ1：輔導策略忠實度

StratL 能成功引導 LLM 遵循 PF 輔導策略。我們在圖 3 報告依第 4.4 節流程得到的結果。PF 分數（滿分 4 分）被用作導師遵循 PF 輔導策略程度的代理指標。我們亦報告學生在「一致性」問題上生成的平均 RSM（部分解法）數量。如第 2.3 節所述，這項指標是 PF 忠實度的最佳代理指標，因為 PF 輔導策略的其中一項目標，就是最大化 RSM 數量。在兩道測試題之中，只有「一致性」是發明型問題，因此只有它能測量 RSM 數量。

在兩道測試題上，StratL 控制的 LLM（V1）都取得比基準 LLM（V2）更高的 PF 分數；在「一致性」題上，這項差異達統計顯著（雙樣本 t 檢定，\(p=.046\)），代表它對 PF 輔導策略的忠實度較高。

此外，基準 LLM（V2）未能讓學生生成多個 RSM；接受 StratL 控制之 LLM 輔導的學生，在輔導過程中平均產生 2.6 個 RSM。這項差異達統計顯著（雙樣本 t 檢定，\(p=.05\)）。就此而言，V1 成功實現 PF 過程的目標，讓學生探索盡可能多的解法。

- 柱上 `N=`：該組有效樣本數。
- 垂直誤差線：圖標題所稱的信賴區間；附件正文沒有提供信賴水準及計算方法。

### 圖 3 解讀

三組比較中，V1 的平均柱高都高於 V2。Consistency 題的 RSM 數量約為 V1 的 2.6 對 V2 的 1.0；正文報告兩組差異 \(p=.05\)。Consistency 題的 PF 分數亦是 V1 較高，正文報告 \(p=.046\)。Country 題同樣呈現 V1 平均值較高，但正文沒有宣稱此差異達統計顯著。

這張圖支持的結論是：在這次小型實地測試中，StratL 比只有基礎導師提示詞的版本，更能讓對話符合作者定義的 PF 過程。它不能證明學生的後測成績、長期保持或新題遷移有所提升，因為圖中測量的是過程代理指標，而不是學習結果。

樣本數非常小且不平衡：Consistency 為 V1 \(N=5\)、V2 \(N=4\)；Country 為 V1 \(N=3\)、V2 \(N=5\)。誤差線相當寬，因此效果量估計不穩定。\(p=.05\) 及 \(p=.046\) 位於傳統顯著性門檻附近，不應解讀成已確立的普遍效果。

對 `wenyan-pilot` 的意義：不能只測「有沒有洩漏答案」；還要預先定義提問式 AI 是否真的完成預期過程，例如是否引導參與者引用文本線索、是否完成規定的自我解釋回合。這些是 manipulation fidelity（操弄忠實度）指標，必須與 S3、S5、S6 的學習結果分開報告。

#### RQ2：學生回饋問卷

回饋問卷沒有發現 StratL 對導師 LLM 的連貫性、同理心或感知有用性造成特定外溢效果。

StratL 對導師 LLM 產生連貫回應的能力沒有影響或影響很小。在兩道題上，StratL（V1）的連貫性得分與無意圖 LLM（V2）相近或略低：在「一致性」題上，V1 為 1.80／3，V2 為 2.25／3；在「國家」題上，兩者都是 3.00／3。我們沒有偵測到任何統計顯著差異。

StratL 不會影響 LLM 產生具同理心回應的能力。兩個版本在感知同理心上都沒有顯著高於另一版本：「一致性」題為 V1 的 1.60 對 V2 的 1.75；「國家」題為 2.67 對 2.20。

StratL 可能透過它要求導師 LLM 遵循的輔導策略，影響導師的感知有用性。我們發現，學生認為沒有意圖的基準版本（V2）比 V1 更有用：「一致性」題分別為 2.00 對 1.20；「國家」題為 2.80 對 2.67。

這並不令人意外，因為 PF 輔導策略可能使學生受挫或被誤解。PF 策略的設計是只在絕對必要時提供協助，這代表學生會花更多時間卡住，並探索次佳解法。相較於提供更多協助的版本，這可能使學生認為該導師比較沒有幫助。詳細結果見表 2。

問卷分數沒有顯示 V1 在主觀體驗上全面優於 V2。V1 的 PF 過程忠實度較高，但在 Consistency 題的有用性得分反而明顯較低。這呈現一項重要張力：較忠實的「不立即幫忙」策略，可能在教學理論上合理，卻讓學生主觀上覺得比較沒有幫助。

然而，各格樣本數只有 3–5 人；正文亦表示未偵測到統計顯著差異。因此，這張表不能證明 StratL 不會傷害使用體驗，只能說這次小樣本沒有偵測到明確差異。

### 5.3 問卷回饋

我們的實地測試證明 StratL 導師具有遵循 PF 的能力。本節提出實地研究回饋中的一些質性觀察。

#### 穩健性

如第 5.1 節所述，學生狀態追蹤程序可能出現標記錯誤。這些錯誤可能進一步破壞意圖選擇，導致選出互相矛盾的意圖。一名學生的回饋正好說明這個問題：「即使我的答案是正確的，AI 還是不斷叫我檢查答案。」

#### 解法限制

一名被分配到無意圖基準版本（V2）的學生抱怨，導師不允許他使用與預期解法完全不同的方法：「AI 只聽它想要的關鍵點，忽略其他所有內容（例如我使用 […] 的想法）。」好的導師應鼓勵原創解法。這指出一項教學問題：在這個案例中，導師透過限制學生，反而對學習造成傷害。

## 6 結論

我們把 LLM 在輔導上的教學限制，表述為「教學導向調控」問題，並提出 StratL 演算法處理此問題。StratL 把學習科學概念與 LLM 結合，使用學生狀態追蹤，以及以專家定義轉移圖為基礎的輔導意圖選擇程序，動態引導 LLM 遵循已建模的教學方法。一項由高中生參與的實地研究，展示 StratL 遵循生產性失敗學習設計的能力。

## 限制

### 評估面向

實地研究在端到端情境中，使用以評分規準為基礎的評估，以及學習者感知有用性。我們主張還需要其他評估指標，例如由多名真人教師，從吸引學生參與、提問品質等面向評估品質。

此外，雖然我們透過實地研究評估 StratL，但學習者對待這項練習的認真程度，可能不如正式課程中的練習。未來應進行具有更高生態效度的研究。

### 整合

雖然輔導可以作為獨立體驗進行探索，但也必須考慮 StratL 之類的系統，如何整合到課堂或正式教育情境。因此，未來研究應探討：（1）如何支援教師調整及個人化導師策略；（2）如何向教師提供相關回饋，以確保系統與課堂內容保持連續；（3）這類導師應如何以最佳方式整合到現有教學結構中。

### 風險

隨著學生在學習過程中愈來愈常使用 AI 工具，我們必須確保這些工具有益於學習。一些研究已以實證方式顯示，生成式 AI 工具可能透過過度依賴等機制傷害學習（Zhai et al., 2024）。

在本研究中，我們使用 StratL，讓教師與學習科學家能控制學生與生成式 AI 的互動，藉此減輕這些影響。然而，在大規模部署前，仍應進一步進行實地研究，檢驗學生使用 StratL-LLM 導師時的依賴行為。Wang et al.（2024c）更廣泛地討論了在教育中使用 LLM 所伴隨的風險。

### 社會面向

學習經驗的社會脈絡在學習中扮演重要角色，而「社會環境」（social surround）甚至是 PF 三個設計層次之一（Kapur and Bielaczyc, 2012）。一般而言，具支持性且協調良好的關係對學習很重要（Roschelle and Teasley, 1995）。為了呈現完整圖像，研究者應探討學生在社會層面如何看待這些導師。

除了認知學習結果之外，也必須考慮學習活動的情意結果，例如社會情緒能力（Alzahrani et al., 2019），以及相較於真人導師，與數位導師互動會如何影響這些結果。

### 資料隱私
